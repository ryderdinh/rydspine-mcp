Cài rydspine

MCP giúp AI rig và làm animation cho nhân vật Spine 4.3 từ file PSD hay ảnh rời. Tải một file, bấm đúp, trả lời vài câu hỏi là xong.

Tải bộ cài cho macOS

rydspine-setup-mac.zip · Safari tự giải nén thành rydspine-setup.command

  1. Mở thư mục Downloads, bấm đúp rydspine-setup.command.
    macOS sẽ báo không thể xác minh nhà phát triển vì file chưa được Apple ký. Bấm Done, vào System Settings → Privacy & Security, kéo xuống và bấm Open Anyway, rồi bấm đúp file lần nữa. (macOS 14 trở về trước: bấm chuột phải vào file → Open.)
  2. Cửa sổ Terminal mở ra và tự tải, tự cài. Khi được hỏi, gõ Enter để đồng ý.
  3. Thấy dòng Xong! là đóng cửa sổ. Mở lại app AI của bạn (Claude Desktop cần thoát hẳn bằng ⌘Q).
Tải bộ cài cho Windows

rydspine-setup-windows.bat · cần Windows 10 trở lên

  1. Bấm đúp rydspine-setup-windows.bat trong thư mục Downloads.
    Nếu Windows hiện Windows protected your PC, bấm More info → Run anyway. File chỉ là script văn bản; bạn có thể mở bằng Notepad để đọc trước.
  2. Cửa sổ dòng lệnh mở ra và tự tải, tự cài. Khi được hỏi, gõ Enter để đồng ý.
  3. Thấy dòng Xong! là bấm phím bất kỳ để đóng. Mở lại app AI của bạn (Claude Desktop cần thoát hẳn từ khay hệ thống).

Cần có trước

Node.js 20 trở lên. Chưa có thì cài bản LTS ở nodejs.org; bộ cài sẽ tự mở trang này nếu thiếu. Ngoài ra cần ít nhất một app AI dưới đây.

  • Claude CodeGhi vào cấu hình người dùng, kèm skill spine-rigging
  • Claude DesktopThêm vào claude_desktop_config.json, có sao lưu
  • CodexThêm vào ~/.codex/config.toml

Mã nguồn được tải về ~/.rydspine/app, dự án lưu ở ~/.rydspine/workspaces. Chỉ app nào có trên máy mới được hỏi; cấu hình cũ luôn được giữ lại. Chạy lại bộ cài bất cứ lúc nào để cập nhật bản mới.

Dùng thử

Mở app AI và nhờ, ví dụ:

Tạo dự án Spine từ file nhan-vat.psd, rig và làm animation đi bộ, rồi export.

Kết quả là .json, .atlas và .png chuẩn Spine 4.3: nạp thẳng vào game, hoặc mở trong Spine Editor bằng Spine → Import Data… (không bắt buộc có Spine Editor).

Gặp sự cố

Bấm đúp mà không có gì xảy ra (macOS)

Mở Terminal, gõ bash (có dấu cách), kéo file rydspine-setup.command vào cửa sổ rồi nhấn Enter.

Báo thiếu Node.js dù đã cài

Đóng hết cửa sổ Terminal hoặc dòng lệnh rồi bấm đúp bộ cài lần nữa. Nếu dùng nvm, đặt bản mặc định bằng nvm alias default 22.

App AI không thấy rydspine
  • Claude Desktop: thoát hẳn app rồi mở lại.
  • Claude Code: chạy claude mcp list, phải có dòng rydspine.
  • Codex: chạy codex mcp list.
Cài thủ công (cho người quen dòng lệnh) 
git clone https://github.com/ryderdinh/rydspine-mcp ~/.rydspine/app
cd ~/.rydspine/app && npm install --omit=dev
node node_modules/tsx/dist/cli.mjs src/setup.ts
