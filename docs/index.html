Install rydspine

An MCP that lets your AI rig and animate Spine 4.3 characters from a PSD or separate images. Download one file, double-click it, answer a few questions and you are done.

Download the macOS installer

rydspine-setup-mac.zip · Safari unzips it into rydspine-setup.command

  1. Open your Downloads folder and double-click rydspine-setup.command.
    macOS will say it cannot verify the developer because the file is not signed by Apple. Click Done, go to System Settings → Privacy & Security, scroll down and click Open Anyway, then double-click the file again. (macOS 14 and earlier: right-click the file → Open.)
  2. A Terminal window opens and downloads and installs everything. When asked, press Enter to accept.
  3. When you see Done!, close the window. Restart your AI app (quit Claude Desktop completely with ⌘Q).
Download the Windows installer

rydspine-setup-windows.bat · needs Windows 10 or later

  1. Double-click rydspine-setup-windows.bat in your Downloads folder.
    If Windows shows Windows protected your PC, click More info → Run anyway. The file is a plain text script; you can open it in Notepad to read it first.
  2. A command window opens and downloads and installs everything. When asked, press Enter to accept.
  3. When you see Done!, press any key to close. Restart your AI app (quit Claude Desktop completely from the system tray).

Requirements

Node.js 20 or later. If you do not have it, install the LTS version from nodejs.org; the installer opens that page if Node is missing. You also need at least one of the AI apps below.

  • Claude CodeAdded to the user configuration, with the spine-rigging skill
  • Claude DesktopAdded to claude_desktop_config.json, with a backup
  • CodexAdded to ~/.codex/config.toml

What the installer does

rydspine — Spine rig & animation MCP setup 1. Node.js ✓ Node 22.11.0 2. Connect to apps Set up Claude Code? [Y/n] ✓ Claude Code Set up Claude Desktop? [Y/n] backup: …/claude_desktop_config.json.bak-… ✓ Claude Desktop 3. PNG previews Download Chromium (~150 MB) so the preview tool can render PNG images? [Y/n] 4. Spine Editor ✓ found Spine; open results with Spine → Import Data… 5. Test the server ✓ server runs, 49 tools ready Done!

The source is downloaded to ~/.rydspine/app and projects are stored in ~/.rydspine/workspaces. You are only asked about apps installed on your machine; existing configuration is always kept. Run the installer again at any time to update.

Try it

Open your AI app and ask, for example:

Create a Spine project from character.psd, rig it, make a walk animation, then export it.

The result is standard Spine 4.3 .json, .atlas and .png files: load them straight into your game, or open them in the Spine Editor with Spine → Import Data… (the Spine Editor is optional).

Troubleshooting

Nothing happens when I double-click (macOS)

Open Terminal, type bash (with a space), drag rydspine-setup.command into the window and press Enter.

It says Node.js is missing, but it is installed

Close every Terminal or command window and double-click the installer again. If you use nvm, set a default version with nvm alias default 22.

My AI app does not see rydspine
  • Claude Desktop: quit the app completely and reopen it.
  • Claude Code: run claude mcp list; it should list rydspine.
  • Codex: run codex mcp list.
Manual install (for command line users) 
git clone https://github.com/ryderdinh/rydspine-mcp ~/.rydspine/app
cd ~/.rydspine/app && npm install --omit=dev
node node_modules/tsx/dist/cli.mjs src/setup.ts
